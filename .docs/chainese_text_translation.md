# Dynamic Content Rules

The following values must NEVER be translated because they are dynamic/database/user-provided content:

- User names
- Email addresses
- Room names
- Resource names
- Resource descriptions entered by users
- Dates
- Times
- Booking purposes entered by users
- Attendee names
- Booking counts
- Capacity numbers
- Database status values when rendered dynamically
- AI-generated booking/user content
- Notification dates and timestamps

Only the surrounding static UI labels must be translated.

---

# Translation Implementation Notes

1. Use Simplified Chinese (`zh`) for the Chinese language.
2. Use the exact static Chinese strings defined in this document.
3. Do not use runtime Gemini/Google translation for these strings.
4. Static translations must come from the local dictionary.
5. Preserve all interpolation variables exactly, for example:
   - `{resourceName}`
   - `{count}`
   - `{total_days}`
   - `{nativeName}`
   - `{error.message}`
6. Do not translate database/user-entered values.
7. Existing English and Bengali translations must remain unchanged.
8. Chinese language switching must work across all pages, dialogs, notifications, toast messages, forms and empty states.
