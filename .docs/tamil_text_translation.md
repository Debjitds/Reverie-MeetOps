## 27. Translation Behavior

When the selected language is Tamil:

```text
English UI text
        ↓
Tamil dictionary
        ↓
Tamil UI
```

When switching back to English:

```text
Tamil UI
        ↓
English dictionary/default strings
        ↓
English UI
```

No runtime AI translation should be used.
