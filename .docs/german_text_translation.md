# 29. German UI Style Rules

Use natural, professional German suitable for a business resource-booking application.

Rules:

1. Prefer concise UI labels.
2. Use sentence-style German for normal messages.
3. Use title-style capitalization only where appropriate for UI headings.
4. Keep technical values, room names, usernames, emails, dates, times, numbers and dynamic values unchanged.
5. Preserve the meaning of the English source text.
6. Do not use literal or unnatural machine-translated wording when the translation above already defines the intended phrase.
7. Use consistent terminology throughout the entire application.
8. Keep `Room 10`, `Room 11`, etc. unchanged because they are resource names.
9. Keep user-generated booking purposes unchanged.
10. Do not translate database values unless they are explicitly localization keys.
